The vision: Created a Template for Rhythm games where the player can import their own songs

The gameplay: Players hit arrow keys in time with the music as notes fall down three lanes. Each note is graded based on timing, hit it perfectly for a Great, slightly off for a Good or Okay. Missing a note or hitting when nothing is there resets your combo.
Score is calculated by multiplying the hit value by your current combo, rewarding consistent play. At the end of the song you receive a letter grade from F all the way up to A+.


Cool Stuf:
  Song Import: players can load any OGG audio file from their computer, so the game works with any song they choose. 
  Custom BPM: players manually enter the tempo of their song before playing, which the game uses to sync note generation to the beat. 
  Grading System: at the end of each run players receive a letter grade from F to A+ based on their final score, along with a breakdown of their    Greats, Goods, Okays, and Misses. 

Future Improvments:
  instead of manually entering a BPM, players could tap along to the beat and the game would calculate it automatically for more accuracy 
  allow players to save their imported songs and BPM settings so they don't have to re-enter them every time they play 
  instead of fully random note generation, design specific patterns that match the energy and structure of the song for a more polished feel 
  Add background animations, particle effects, and screen shake that react to the music to make the experience more immersive
